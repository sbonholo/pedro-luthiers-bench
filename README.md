# Luthier's Bench

Build your own cello, step by step.

Made by **Pedro** with Claude.

- Play (Claude Artifact): https://claude.ai/artifact/HG8V6DdsL2FdC36MzktuGK
- Source: `index.html` + `fonts/` (self-hosted woff2, OFL). No third-party CDNs; serve the folder or open `index.html` in any browser.
- Progress saves automatically in the browser (localStorage); returning players can continue where they left off.
